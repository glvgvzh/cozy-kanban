# Cozy Kanban

PWA-приложение для управления задачами с интеграцией Telegram.

Приложение позволяет создавать, редактировать и отслеживать задачи, получать уведомления о дедлайнах и управлять задачами через Telegram-бота.

Проект создан как pet-проект для изучения React, PWA, Node.js, работы с API и серверной разработки.

## 🚀 Возможности

### Управление задачами

- создание, редактирование и удаление задач
- перемещение задач между колонками
- drag & drop на desktop
- адаптивный мобильный интерфейс
- навигация между колонками свайпами
- поиск задач
- фильтрация по приоритету
- сортировка по дедлайну

### Задачи

Поддерживаются:

- описание задачи
- приоритеты:
  - низкий
  - средний
  - высокий
  - критический
- дедлайны
- отслеживание просроченных задач

### Уведомления

В приложении реализован центр уведомлений:

- уведомления о задачах с дедлайном сегодня
- напоминания о задачах с дедлайном завтра
- уведомления о просроченных задачах

Также реализована отправка уведомлений в Telegram.

### PWA

Приложение поддерживает:

- установку на устройство
- работу в standalone-режиме
- offline-режим
- адаптивную мобильную версию
- push-уведомления

### Telegram-интеграция

Реализовано:

- создание Telegram-бота
- привязка доски к Telegram через уникальный код
- хранение данных доски на сервере
- создание задач через Telegram
- отправка уведомлений о дедлайнах и просроченных задачах

## ⚙️ Установка и запуск

Для полноценной работы приложения необходимо запустить frontend, backend API сервер и Telegram-бота

### Frontend

Установить зависимости:

```bash
npm install
```

Запустить приложение:

```bash
npm run dev
```

---

### Backend

#### API сервер

```bash
node server/server.js
```

#### Telegram бот

Создать файл `.env`:

```env
TELEGRAM_BOT_TOKEN=your_token
```

Запустить Telegram-бота:

```bash
node --env-file=.env server/bot.js
```
